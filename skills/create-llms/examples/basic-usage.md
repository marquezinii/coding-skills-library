# Basic `llms.txt` example

For a small repository, keep the index short and link only to stable, high-value documents.

```text
# Example Project

> A small service that demonstrates the public API.

## Documentation

- [README](README.md): Setup, usage, and development commands.
- [API guide](docs/api.md): Supported endpoints and examples.
```

Validate every relative link from the repository root before saving `llms.txt`.
